# Global Financial Performance Dashboard

🚀 **Transforming Financial Data into Actionable Insights with Power BI** 📊

I’m excited to share a Power BI dashboard I recently built to analyze and visualize key financial metrics across markets and product lines. This dashboard offers a high-level yet insightful view into **Gross Sales, Cost, and Profit performance**, helping stakeholders make informed decisions with confidence.

🔍 **Key Highlights:**
- 💰 **Gross Sales:** $255.86M | 🧾 **Cost:** $203.67M | 📈 **Profit:** $33.79M
- 🌍 **Sales by Country**: Track performance across the US, Canada, Mexico, France, and Germany with an interactive geo-map.
- 🛒 **Product Performance**: Compare revenue contributions across top-selling products like *Paseo, VTT, Velo Amarilla,* and more.
- 📊 **Segment Analysis**: Deep dive into Gross Sales & Profit Margins by customer segments — from Government and Enterprise to Channel Partners.

✨ **Tools & Features Used:**
- Microsoft Power BI Desktop
- DAX for dynamic measures
- Interactive slicers and map visualizations
- Clean, executive-friendly design for quick data storytelling

💡 **Impact:** This dashboard helps financial teams:
- Identify top-performing markets and products
- Monitor profitability trends
- Prioritize strategic investment based on segment efficiency

I believe that the ability to translate raw data into clear, compelling insights is key to driving better business outcomes — and tools like Power BI make it possible. 🔧
